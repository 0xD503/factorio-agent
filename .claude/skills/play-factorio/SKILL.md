---
name: play-factorio
description: >-
    Play Factorio with or for the user through this repository's fx harness,
    solo or in multiplayer co-op. Use when the user asks to play Factorio, to
    start or resume a game, to host or join a multiplayer game, or to chat with
    players in the game.
---

1. Read `AGENTS.md` in the repository root completely; it has the rules (fair
   play, safety, co-op etiquette).
2. Run `./fx doctor`, then `./fx session list`. Resume the session the user
   means or create one as AGENTS.md describes.
3. Read the session's `NOTES.md` and the relevant `./fx kb list` items before
   acting.
4. Play with `./fx` commands. Keep `NOTES.md` current and write lessons to the
   right layer as you go.
